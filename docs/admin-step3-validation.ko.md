# 3단계 — Bot Control 설치·관리자 권한 검증

검증일 2026-09-21. 마법사 0.6.0 / Bot Control 0.6.2 / Mattermost 11.11.0 / Windows Docker Desktop Linux AMD64.

## 실제 임시 서버에서 확인

GUI와 같은 암호화 입력·CLI 작업 경로로 2단계 서버를 만든 뒤, 기존 계정·팀·채널을 유지하며 Bot Control을 추가했습니다.

- 동봉 패키지 해시 검증, 업로드, 활성화, 플러그인 자체 관리자 API 응답 확인.
- 익명 관리 API 요청은 401.
- 일반 사용자에 대한 Bot Control 접근·등록 목록·정책 적용 요청은 403.
- 일반 사용자의 Mattermost 기본 플러그인 활성화·비활성화·삭제·설정 변경 요청은 403.
- 일반 사용자 토큰에 관리자 ID 헤더를 추가해도 403.
- 설치가 끝나면 `PluginSettings.EnableUploads=false`, 플러그인은 활성 상태 유지.
- 서버 재시작 후 플러그인 응답 유지.
- 동일 설치 재실행 시 플러그인 중복 생성·교체 없음.
- 테스트 컨테이너·네트워크·volume만 정리. 기존 로컬 Mattermost와 GB10은 변경하지 않음.

## 자동 테스트

- 관리자 마법사 회귀 검사 60개(기존 52개 + 플러그인 모드 전환·중단 복구·패키지 검증).
- 플러그인 Go 테스트: 익명·일반 사용자·팀 관리자·역할 문자열 위조·삭제 계정·관리자 역할 봇 거부, 등록 정보 암호 비노출, 다른 연결로 암호 전달 거부.
- Dashboard 인증 비활성화·로그인 거부·세션 누락·리디렉션·원격 오류 정보 노출 거부는 로컬 모의 Dashboard로 검증. 실제 연구실 에이전트의 프로필·게이트웨이는 수정하지 않음.
- 웹앱 production 빌드 및 관리자 WPF 화면 로딩/비동기 작업 확인.
- 기존 사용자 마법사의 테스트도 유지.

## 범위 밖

Hermes Dashboard 직접 접속의 Mattermost SSO/NetBird ACL, 실제 연구실 봇에 정책 적용, GB10 배포, 봇 생성·토큰 발급 UI, Windows 재부팅/로그인 전 무인 실행은 이번 단계의 완료 항목이 아닙니다. 봇 생성·토큰 발급은 4단계입니다.

패키지는 `assets/bot-control/com.infonet.bot-control-0.6.2.tar.gz`이며 SHA-256은 `config/bot-control.json`에서 확인할 수 있습니다. 임의 온라인 최신판으로 대체하지 않습니다.
