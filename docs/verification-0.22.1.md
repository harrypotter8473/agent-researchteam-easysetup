# 0.22.1 검증 범위

## 변경

보드의 작업을 네모 칸반 카드로 표시합니다. 앞면에는 짧은 제목만 남기고 담당·요약·
현재 상태·감사·결과 파일은 클릭 상세에서 확인합니다. 기존 '분석·보고서' 제목은
화면에서만 '분석 보고서'로 표시하며 저장된 원본과 ID를 변경하지 않습니다.
동일 작업 ID의 카드는 실제 조회 상태에 따라 대기 / 진행 중 / 확인 필요 / 완료로 이동합니다.
미착수와 실제 실행을 구분하며 알 수 없는 상태는 진행 중으로 가장하지 않고 확인 필요로 표시합니다.
높이를 104px에서 64px로 줄이고 좁은 화면에서는 보드 내부를 가로 스크롤하며 네 칸을 유지합니다.

## 검증

- 실제 app.js를 실행하는 Node 회귀: 제목만 표시, 동일 카드 객체·ID의 대기/실행/보류/완료 이동,
  사용자 예시의 전체 요약·파일 크기 클릭 표시, 담당 필터·파일·활동 조회, 엄격한 중간/최종감사 구분.
- 브라우저 로컬 fixture: 실제 UI에서 분석 보고서 카드 1개의 대기 → 진행 중 → 확인 필요 → 완료 이동,
  클릭 상세, 600px 화면의 동일 가로 칸 유지와 페이지 전체 가로 넘침 없음.
  fixture는 화면 테스트이며 실제 연구·감사 통과나 설치 준비 완료로 표시하지 않습니다.
- 완료한 0.22.0 실제 S1의 보존된 Git·활동·파일 기록을 읽기 전용으로 열어 새 카드와 상세를 확인합니다.
  이전 격리 종료 시 완료 이벤트가 저장되지 않은 총괄 실행 카드 1개도 원기록대로 보존합니다.
- Python 대시보드/활동 28개와 Node Mattermost 플러그인 회귀를 확인합니다.
- 최종 배포 ZIP의 모든 FILES.sha256, 70개 팀 payload와 소스 일치,
  새 ZIP 추출본의 Windows PowerShell 5.1 마법사 SmokeTest를 확인합니다.
- Mattermost 플러그인 0.2.5에 새 UI를 빌드하고 독립 보드/내장 UI 일치 검사, Go 서버 및 플러그인 설치 회귀를 확인합니다.
- 기존 API가 display_name/project_label을 제공하지 않아도 화면에서 S1/S2/S3 이름을 알아보기 쉽게 표시합니다. 사용자 지정 표시 이름이 우선이며 일반 연구 프로젝트의 이름은 임의 변경하지 않습니다. 파일·요청·API에는 원래 식별자를 그대로 사용합니다.
- 기존 로컬 Mattermost의 보드 플러그인만 갱신합니다. 실제 화면에서 네 칸·작은 제목 카드·클릭 상세를 확인하며 연구팀 payload·설치 바인딩·원장·감사·기존 검증 기록은 교체하지 않습니다.

## 유지 및 한계

3+1·페르소나·독립 실행기·총괄 후속 판단·권한·근거 재사용·한도·강제 버전별 블라인드 감사·
설치 준비 판정은 바꾸지 않습니다. 수동 카드 이동으로 상태/감사를 쓰는 기능은 없습니다.
기존 서버의 보드 플러그인만 갱신하며 계정·대화·문서·연구 프로필·실행 서비스·인증·기록을 보존합니다. 모델을 새로 호출하지 않습니다.
기존 0.22.0 실제 S1 통과는 이전 후보의 기록이며 새 0.22.1 실모델 인증이 아닙니다.
새 PC 전체 설치와 실제 S1/S2/S3 재실행은 이번 UI 수정 검증 범위가 아닙니다. GitHub 게시와 자동검사는 해당 커밋/릴리스의 실제 상태로 별도 확인합니다.
