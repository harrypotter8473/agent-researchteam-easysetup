# 0.18.0 검증 범위

상태: 프리릴리스. 최신 후보를 새 PC에서 처음부터 설치한 뒤 S1·S2·S3까지 모두 통과했다고 보증하지 않습니다.

## 포함한 구현

- 총괄·조사·분석/집필·감사의 3+1과 전체 기존 페르소나.
- Git 작업 보드·독립 역할 실행기·실행 결과를 보고 다음 작업을 정하는 총괄.
- 현재 결과물 버전에 묶인 중간·최종 블라인드 감사, 권한 제한, 저장 근거 재사용.
- 한국어 웹 보드의 프로젝트·작업·결과·승인 요청·실행 기록. Mattermost에는 중요한 보고만 게시.
- 원클릭 봇·토큰 기본 구성, 연구 프로필 격리, 상태 기록 실패 처리와 중단 작업 체크포인트.
- 중복 파일 전달 방지와 실제 첨부 재다운로드 검증.

## 실제 검증과 미완료 사항

- 이전 round06 설치 후보는 같은 PC의 Mattermost·연결 모델로 S1·S2·S3, 감사, 최종 파일, 첨부 재다운로드 검증을 통과했습니다.
- 이후 조용한 Mattermost 보고·업로더·상태 기록을 보완한 최신 round10은 다른 설치 바인딩입니다. round06 성공을 최신 후보의 성공으로 대체하지 않습니다.
- round10 실제 설치와 S1 조사가 시작됐지만, 사용자가 직접 처음부터 설치하기로 하여 실행을 종료했습니다. 최신 후보의 S1·S2·S3 전체 완료는 미검증입니다.
- 실제 서비스 상태 파일을 잠시 읽기 잠금한 통제 검사에서는 서비스와 자식 실행기가 유지됐고 상태 관측이 복구됐습니다. 이 결과가 과거 서비스 종료의 정확한 원인을 확정하지는 않습니다.
- 이전 후보에서는 사람 계정의 멘션 접수와 같은 스레드의 최종 응답을 확인했습니다. 최신 quiet 설정 적용 후의 동일 입구 검사는 아직 완료하지 않았습니다.
- 새 Windows PC 최초 설치, 원격 Windows CI, 최신 후보의 전체 실모델 검증은 별도로 확인해야 합니다.

무료 모의·패키지 검사는 실제 모델 연구 품질이나 설치 완료의 증명이 아닙니다. 설치 마법사는 현재 설치에 묶인 실제 S1·S2·S3·감사·첨부 증거가 없으면 사용 준비 완료로 표시하지 않습니다.

개인 인증, 봇 토큰, 실행 중 데이터, 실제 대화·연구 결과, 개인 경로가 포함된 개발 작업 일지는 공개 소스와 ZIP에서 제외합니다.
