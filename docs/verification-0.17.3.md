## 원인과 수정

실제 0.17.2 설치의 `ResearchReportsBoardinitFailed`를 복사한 보드에서 재현했습니다.

`research_board.py`가 같은 배포 폴더의 `audit_gate`를 찾지 못했습니다.

자기 파일의 실제 위치로 확인한 배포 폴더만 추가합니다. 작업 폴더는 추가하지 않습니다.

초기화 실패의 원래 오류는 토큰을 가린 비공개 `workspace-init-error.json`에 남깁니다.
