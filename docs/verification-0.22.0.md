# 0.22.0 검증 범위

## 변경과 불변

사람이 읽는 프로젝트명, 진행 중/확인 필요/작업 완료 묶음, 짧은 카드와 클릭 상세,
줄바꿈 요약·결과 파일 스크롤·간단한 활동 묶음을 적용했습니다.
표시 이름만 바꾸며 프로젝트 ID·폴더·Git 이력·감사 판정·권한은 바꾸지 않습니다.
과거 오류·반려는 보존하고 같은 대상·감사 범위의 후속 통과가 확인된 경우에만 완료 이력으로 표시합니다.
중간감사를 최종감사로 대신하지 않습니다. 새 요약을 위한 모델 호출은 없습니다.

3+1 전체 페르소나, 실행기, 범용 필수 검증 복구, 현재 버전별 중간/최종 블라인드 감사,
근거 재사용·모델·한도·마법사 준비 판정은 0.21.2와 같습니다.

## 현재 확인

- 실제 완료한 격리 0.21.2 기록을 새 코드로 읽어 프로젝트명·카드·요약·담당 필터를 화면 확인했습니다.
- 720px 화면의 단일 열, 요약 줄바꿈, 결과 파일 목록 제한 높이, 가로 넘침 없음 확인.
- 표시/API 회귀는 무료 검증이며 실제 새 후보의 S1 실행과 별개입니다.
- 무료 회귀: Python 전체 184개 통과 후 잘못된 메타데이터의 보완 검사 1개를 추가해 관련 7개 재통과.
  Windows PowerShell 5.1/7 각각 20묶음+마법사, 배포 106개 검사, Node 보드/플러그인과 Go 서버 검사 통과.
  별도 테스트 가상환경의 모델 라우팅 29개 검사도 통과했습니다. 개인 Python 환경에 패키지를 설치하지 않았습니다.
- 새 ZIP 추출본의 119개 파일 SHA-256·70개 payload·추출 마법사 실행을 확인했습니다.
- 같은 추출본의 마법사 프로필/작업공간 구성 함수를 사용한 별도 실제 S1은 2026-10-23 10:21:53 UTC에 exit 0으로 완료했습니다.

## 실제 S1 결과

- 기존 Mattermost의 새 비공개 채널, 격리된 네 프로필·런타임·작업공간에서 gpt-6.1-sol을 사용했습니다.
- 총괄 계획 → 조사 → 독립 중간감사 → 분석·집필 → 독립 최종감사 → 총괄 전달을 수동 배정 없이 수행했습니다.
  조사 담당이 원문 9편을 보존·추출했고 집필 담당은 같은 근거를 재사용했습니다.
- 중간감사 10:02:16 UTC, 최종감사 10:20:55 UTC 모두 현재 파일·작업 버전에 바인딩된 pass이며 findings는 비어 있습니다.
- 네 역할·원장 무결성·원문 보존·필수 중간/최종감사·최종 파일 검사를 모두 통과했습니다.
  관측기는 스스로 업로드하지 않고 총괄의 실제 Mattermost 첨부를 재다운로드했습니다.
- Word SHA-256: `6e6c8c043e1f805a3f96074028e30cce49dba53f58f355ca9e27cb2f590fd99d`.
  Markdown SHA-256: `ac5e68da8a6d20b53ee8af27babca185c3c3eacd566966a24d4a2600128ccb0d`.
- 검증 payload manifest: `30f3014645048f88d1451e79f47470b5799183aaf2af98f4a33b16328e7273a1`.
- 기존 실행 횟수·재시도·시간 한도를 그대로 사용했고 승인 플래그·감사·원장을 초기화하지 않았습니다.
  완료 후 격리 서비스만 종료했으며 실패/검증 기록은 보존했습니다.

## 범위 한계

기존 18065 서버/계정/대화/문서·운영 프로필/서비스·개인 Hermes/인증은 보존합니다.
검증은 별도 로컬 프로필·런타임·비공개 채널에서 수행하며 새 Windows PC 초기 설치 인증은 아닙니다.
0.21.2의 실제 S1→S2→S3 결과는 [이전 기록](verification-0.21.2.md)이며
0.22.0의 S1-only 결과를 전체 설치 준비 완료로 대체하지 않습니다.
제품의 전체 시나리오 목록이나 `live-test.json`을 수정하지 않는 별도 S1 관측기를 사용했습니다.
실험의 native 진입 어댑터와 access token만 든 격리 인증은 배포본에 포함하지 않습니다.
초기 격리 의존성 준비에서 공식 bootstrap이 소스의 생성된 frontend를 재빌드했습니다.
이후 실험에만 공식 `HERMES_DISABLE_LAZY_INSTALLS=1`을 적용해 이미 준비된 의존성을 재사용하고
추가 자동 소스 업데이트를 막았습니다. 개인/전역 설정을 바꾸거나 제품 검증을 생략한 것이 아닙니다.
옛 버전이 이미 잘라 저장한 요약은 복원하지 못합니다. 원래 상세 기록은 그대로 유지됩니다.
Word 전체 페이지 시각 배치는 별도 검증 대상입니다.
