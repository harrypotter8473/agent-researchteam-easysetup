# 2단계 관리자용 마법사 검증 기록

검증일: 2026-09-21. Windows PC의 로컬 Docker Desktop Linux/AMD64 엔진에서 수행했습니다.

## 통과

- 관리자 입력·경로·포트·권한·비밀정보·재시도 회귀 테스트 52개: Windows PowerShell 5.1과 PowerShell 7.
- CLI 계약 테스트 33개: 명시적 승인 없는 서버 생성, 입력 파일 누락, transport 외부 파일 접근 거부 포함.
- 관리자 WPF 화면 로딩, 기본 동의 해제, 비밀번호 빈 값, 숨김 CLI 작업의 비동기 JSON 처리와 완료 상태 전환.
- 기존 사용자용 단위·보안·CLI·WPF·Dashboard·Mattermost Desktop 회귀 테스트.
- PowerShell 문법/UTF-8 BOM 및 배포 파일 목록 검사.

실제 Docker 검증은 임시 18066 포트와 무작위 배포 ID를 사용했습니다. GUI와 동일한 **DPAPI 입력 → 별도 CLI 프로세스 → 완료 이벤트** 경로로 다음을 확인했습니다.

1. 고정된 공식 이미지 다운로드와 DB·Mattermost 기동.
2. 최초 관리자 생성, 실제 로그인, `system_admin` 역할 확인.
3. 초대 기반 팀·기본 채널 생성.
4. 익명 추가 회원가입 거부(HTTP 403).
5. 관리자가 만든 일반 계정의 시스템 설정 API 접근 거부(HTTP 403).
6. 채널에 검증 메시지를 작성한 후 컨테이너 재시작, 동일 메시지 유지.
7. 새 CLI 프로세스로 이어서 실행해도 관리자·팀·채널 ID 불변.
8. 암호화 전달 파일 제거, 작업 출력에 관리자 비밀번호가 없음을 확인.

검증 후 해당 임시 서버의 컨테이너·네트워크·volume과 임시 설치 기록만 제거했습니다. 내려받은 공식 이미지 캐시는 유지했습니다. 기존 `mattermost-preview` 및 다른 로컬 컨테이너의 중지 상태는 변경하지 않았고 GB10에는 접속·배포하지 않았습니다.

## 아직 검증하거나 구현하지 않은 것

- 사용자가 정한 실제 관리자 계정으로 운영 서버 설치 및 브라우저 수동 로그인.
- Windows 재부팅 전후, 로그인 전 무인 서버 시작.
- Linux/GB10 서버에 이 마법사로 배포, ARM64, NetBird 외부 접근, TLS.
- Bot Control 플러그인 설치·별도 권한 검사, 봇 생성·토큰 발급.
- 다른 PC의 신규 Docker Desktop 설치, 데이터 백업·복구·삭제 마법사.

따라서 이번 완료 의미는 **2단계 Windows 로컬 테스트용 구현과 통합 검증**입니다. 전체 5단계나 운영 배포가 완료된 것은 아닙니다.
