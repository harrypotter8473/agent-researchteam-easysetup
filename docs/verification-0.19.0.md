# 0.19.0 검증 범위 — 2026-10-22

## 구현

- 기존 3+1 연구 실행기·전체 페르소나·현재 버전별 중간/최종 블라인드 감사·권한 제한·근거 재사용은 변경하지 않았습니다. `team/manifest.json` 및 팀 페이로드도 기존 버전 그대로입니다.
- 새 Mattermost 플러그인 `com.hermes.research-board` 0.1.2는 팀 내부 경로와 왼쪽 사이드바·채널 헤더 입구를 제공합니다. 프로젝트·작업·문서·감사·사용자 결정 요청·읽기 쉬운 로그를 기존 한국어 보드에서 읽습니다.
- NST Wordmark 0.1.0은 사용자 기존 패키지 그대로입니다. 원본 해시 `1d9d443ef27f245d312de1ccd8287230b967fc27c999fbd4f4339df171dab772`를 보존했습니다. 기존 GIST 플러그인은 비활성화하며 원본 파일은 변경하지 않습니다.
- 새 설치의 기본설정 과정은 두 플러그인을 자동 설치·활성화합니다. 기존 설치에는 보드·NST만 연결하는 별도 버튼이 있습니다.
- 서버·현재 Windows 사용자·연구팀 소유권, 패키지 SHA256, 열람 사용자와 채널 참여를 검증합니다. 비밀값은 서버·비공개 연결 폴더에만 저장하며 명령 인자·브라우저에 전달하지 않습니다.

## 현재 PC에서 실제 확인

- 사용자가 설치한 기존 연구용 Mattermost의 플러그인 두 개를 설치·활성화했습니다. 보드 서버 → Docker 호스트 연결 → 원래 보드 API까지 실제 왕복을 확인했습니다.
- 설치 직전 진행 중인 연구가 없는 것을 확인했고, 적용 후 S1·S2·S3 통과 파일·팀 설정·개인 및 연구 프로필의 설정·인증 등 보존 대상 22개 파일의 SHA256이 최초 기준과 일치했습니다.
- 익명 접근, 위조한 사용자 ID 헤더, 비밀값 없는 설치 확인 및 틀린 비밀값은 실제 서버에서 403으로 차단됐습니다. 설치 확인용 비밀값은 연구 문서를 읽는 권한으로 쓰이지 않습니다.
- 플러그인 업로드는 적용 중에만 열고 종료 시 다시 잠갔습니다. 같은 설정 재적용 시 Mattermost 컨테이너와 보드 연결 프로세스가 재시작되지 않는 것을 확인했습니다.
- 실제 researcher 로그인 후 좁은 화면·데스크톱 폭에서 보드를 열었습니다. 원래 채널 목록이 유지된 채 채널 중앙에 보드가 나타났습니다. S1·S2·S3 각각 작업 4개 완료·현재 버전 감사 상태, 저장된 보고서 본문, 채팅 복귀·사이드바 재진입을 확인했습니다. 사용자 정정에 따라 GIST를 비활성화하고 NST·BETA VERSION으로 교체한 실제 화면도 확인했습니다. 보드 패키지 자체는 동일한 해시를 유지했습니다.
- 보드의 Word 다운로드를 실제 실행했고 저장된 버전과 SHA256이 일치했습니다. 이 확인은 이미 생성된 결과 파일의 전달 확인이며 새 연구 실행이 아닙니다.
- 이 검증 중 모델 호출이나 새 S1·S2·S3 실행은 하지 않았습니다. 기존 설치의 통과 기록을 보존한 것이지 0.19.0 새 Windows 설치의 실모델 검증을 대신한 것은 아닙니다.

## 무료 검증

- PowerShell 구문·UTF-8 BOM 52개 스크립트, 저장소 공개 파일 검사 통과.
- 플러그인 설치 경계 모의 검사 34개 통과: 실제 mmctl 배열 목록, NST 적용 시 GIST 비활성화, 안전한 재적용·소유 버전 갱신·알 수 없는 플러그인 거부·서명 필수 정책 보존·실패 후 업로드 잠금·연구 실행 중 재시작 거부.
- Go 서버 권한·읽기 전용 경로·비밀값 비노출·연결 재사용, Python 연결 프로그램 경로·권한 검사, 브라우저 플러그인 등록·상대 API 경로 검사.
- 기존 연구팀 설치 모의 회귀 82개, Python 전체 무료 회귀 143개 통과. 배포 ZIP 재현성·전체 해시·포함/제외 파일·추출본 GUI 108개 검사 통과.

모의 검사는 실제 연구 완주를 의미하지 않습니다. 원격 Windows CI와 새 PC 전체 설치는 이번 로컬 검증에 포함하지 않았습니다.

최초 GitHub Windows CI에서 네 `SOUL.md`의 Git 저장본 줄바꿈(LF)이 기존 검증 원본(CRLF)과 달라 배포 해시 검사가 실패했습니다. 페르소나 문구와 기존 manifest는 변경하지 않고 검증된 원본 바이트를 Git에도 그대로 저장하도록 보정했습니다. Git 체크아웃 직후 고정 페이로드 검사도 추가했습니다. 이 배포 보정은 새 실모델 실행을 의미하지 않습니다.

## 적용 범위와 남은 설정

현재 PC의 보드 플러그인 실제 적용과 로그인된 화면까지 확인했습니다. 0.19.0으로 초기화된 새 Windows PC 설치·실모델 S1·S2·S3 재실행·원격 CI는 수행하지 않았습니다.
보드 열람 기본 허용자는 마법사에서 선택한 연구 요청자 한 명이며, 다른 사용자 허용은 시스템 관리자가 명시적으로 설정해야 합니다.
