# NST 0.20.0 코드 정리 검증

로컬 무료 회귀를 통과한 프리릴리스입니다. 완료된 검사와 미실행한 실제 설치를 구분합니다.

## 기준과 삭제 범위

기준 커밋은 `2fcfbd69a3a85b0c4e919aa0d508694753890c74`입니다. Git 이력에서 삭제 코드를 복구할 수 있습니다.

- 단독 사용자·관리자 GUI, CMD, XAML과 관련된 전용 검사·설명서 제거.
- Mattermost Desktop 클라이언트 설치·서버 목록 등록 기능과 고정 설정 제거.
- 구형 Bot Control 0.6.2 패키지·설정·설치 및 개인 봇 등록 코드 제거.
- 구형 Lab 프로필 복제·개인 Dashboard·정기 업데이트 예약 작업 코드 제거.
- 사용자·관리자·연구용 3중 배포 대신 NST 연구팀 ZIP 하나만 생성.

연구팀 마법사에 필요한 서버·관리자 확인, 네 봇·토큰 발급, 암호화 입력, 소유권·Compose 전환·권한 검사는 남겼습니다.
DPAPI 암호화 계약과 기존 공개 함수 이름은 유지하므로 기존 봇·DB 자격증명을 읽는 형식이 바뀌지 않습니다.

## 변경하지 않는 기능

`team/` 전체와 manifest, 네 SOUL.md의 검증된 바이트, 한국어 작업보드·NST 플러그인 패키지는 변경하지 않습니다.
따라서 3+1 실행기·총괄 후속 판단·버전별 강제 블라인드 감사·근거 재사용·모델 분리·한도·실제 S1/S2/S3 설치 완료 판정은 이번 정리 대상이 아닙니다.

## 검증 범위

새 소스의 무료 회귀검사, 단일 ZIP 재현성과 모든 파일 체크섬, 새 압축 해제본의 GUI 및 기능 검사를 수행합니다.
CI는 Windows PowerShell 5.1과 PowerShell 7, Python 팀·감사·보드·라우터, Go/JavaScript 플러그인과 비밀값 검사를 구분합니다.
삭제한 제품의 전용 테스트만 제거했고 기존 연구·설치·보안 테스트는 유지합니다. 실패한 테스트의 종료 코드가 뒤의 성공에 가려지지 않게 검사별 하위 프로세스를 사용합니다.

이번 작업은 소스 정리입니다. 현재 PC의 Mattermost·연구 프로필·서비스·기록과 개인 Hermes·인증·Docker/WSL에는 적용하지 않습니다.
실제 모델 S1·S2·S3과 새 PC 전체 설치는 재실행하지 않았으며, 모의 성공을 해당 실사용 성공으로 표시하지 않습니다.
기존 실행기의 실제 검증 기록은 [0.19.0 검증 범위](verification-0.19.0.md) 및 이전 기록과 구분합니다.

## 로컬 확인 결과 (2026-10-22)

- Windows PowerShell 5.1: 전체 18개 회귀 묶음과 Research GUI smoke 통과. 설치·보안·기존 Hermes/인증·서버·봇·Docker·연구 설정/실행·마이그레이션·플러그인 검사를 포함합니다.
- PowerShell 7: 위 회귀와 배포 검사를 포함한 19개 묶음 및 Research GUI smoke 통과.
- NST 전용 검사 33개: 삭제 기능 부재, 단일 진입점, 필요한 백엔드, 기존 DPAPI 자격증명의 양방향 호환 확인.
- 단일 ZIP 검사 105개: 재현성·전체 파일 체크섬·팀/플러그인 고정 해시·GUI와 추출본 CLI의 기본 거부 승인 검사. 기존 설치는 실행하지 않음.
- Python 무료 연구 회귀 143개: Git 보드·총괄 후속 판단·감사 버전 무효화·권한·중단 복구·메모리/근거·서비스·웹 보드·관찰된 첨부 전달 검증 통과.
- 모델 분리 정책 pytest 29개 통과. 기존 시험의 기본 텍스트 인코딩 의존성은 테스트 실행의 UTF-8 옵션으로 일관화했으며 team 파일은 바꾸지 않았습니다.
- Go 서버 권한 검사, JavaScript 채널/사이드바/읽기 전용 렌더링, workflow YAML·릴리스 선행 검사 조건 확인 통과.
- team 전체·manifest·네 SOUL과 NST/작업보드 플러그인 소스·패키지는 기준 커밋 대비 변경 없음.
- 저장소 현재 파일 202→187개, PowerShell/UI/실행기 스크립트 줄 수 17,882→14,721. 구형 Bot Control 바이너리 10,954,672바이트 제거. Git 과거 이력과 현재 설치는 보존.

기준 원격 CI의 마지막 실행은 도중 취소됐으므로 통과로 표시하지 않습니다. 새 정리본의 원격 Windows/팀/비밀값 검사는 해당 게시 커밋의 GitHub Actions에서 별도로 확인합니다.
