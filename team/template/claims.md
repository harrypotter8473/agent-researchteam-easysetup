# Claims ledger

The spine of the paper. Nothing appears in the text that is not a row here, and the
abstract and introduction may assert only `supported` rows.

Maintained by `research-worker`. Verified by `research-reviewer` (referee mode). Never edited by
a reviewer.

**Status:** `supported` — artifact exists and establishes it · `partial` — artifact
establishes a weaker version · `unsupported` — no artifact yet · `cut` — removed from the
paper, kept here so it is not reintroduced.

| ID | Claim | Asserted in | Evidence artifact | Status | Notes |
|---|---|---|---|---|---|
| C1 | *(the headline claim, in the form it appears in the abstract)* | abstract, §1, §5.1 | `evidence/` | unsupported | |
| C2 | | | | unsupported | |

Claims hide in adjectives. "Substantially faster", "robust to distribution shift",
"scales to" and "practical" are all claims and each needs a row.
